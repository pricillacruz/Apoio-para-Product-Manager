A Anatomia de um Sistema

Esqueça os códigos complexos. Pense em um restaurante de luxo.

Frontend

É tudo o que o usuário vê, clica e interage (site, aplicativo).

O Salão do Restaurante

A decoração, o cardápio bonito, as mesas e a música. Tem que ser agradável e fácil de navegar.

API

A ponte de comunicação entre o que você vê (Front) e onde a mágica acontece (Back).

O Garçom

Você não entra na cozinha para fazer seu prato. Você pede ao garçom (API), que leva o pedido lá pra trás e te traz a comida.

Backend & DB

A inteligência invisível. Servidores processando regras de negócio e salvando no Banco de Dados.

A Cozinha e a Despensa

É onde o chef cozinha (processamento) e a despensa onde guarda os ingredientes (Banco de Dados). É feio, quente, mas faz o negócio funcionar.

Cloud & DevOps (Simplificado)

Computação em Nuvem (AWS, GCP)

"Servidores virtuais alocados sob demanda via rede."

Tradução: É o "AirBnb" de computadores. Em vez de você comprar um servidor de R$ 50 mil e colocar numa sala (e rezar pra não faltar luz), você aluga o computador da Amazon por hora.

CI/CD (Deploy)

"Continuous Integration and Continuous Deployment."

Tradução: É a esteira de produção da fábrica. Quando o dev termina de escrever o código, essa esteira testa automaticamente, empacota e coloca no ar no aplicativo do cliente, sem ninguém precisar copiar e colar arquivos.

Dicionário Tech: Traduzindo a Sopa de Letrinhas

Entenda de uma vez por todas o que cada termo faz no ecossistema de software.

API Gateway / Router

É a portaria do condomínio. Ele recebe todas as requisições de fora, verifica a segurança (quem é você?) e direciona para o prédio (microsserviço) correto.

Containers (Docker)

É uma caixa de papelão mágica. O dev empacota o código junto com tudo o que ele precisa para rodar. Assim, o clássico problema "na minha máquina funciona" acaba, pois o pacote roda igual em qualquer lugar.

Kubernetes (K8s)

É o capitão do navio (Orquestrador). Ele gerencia milhares de containers. Se um container morre, o Kubernetes cria outro no lugar automaticamente. Ele decide onde colocar cada caixa.

Filas (Kafka, RabbitMQ)

É a senha do banco. Para não sobrecarregar o sistema com 1000 requisições simultâneas, os pedidos são colocados em fila e processados um por um.

Observabilidade

É o hospital dos sistemas. É composta por 3 pilares principais para entender a saúde do software:

  • Logs: Diário de bordo (o que aconteceu?).
  • Métricas: Painel do carro (está lento? gastando muita CPU?).
  • Traces: GPS (qual o caminho exato o dado fez no sistema?).

CI/CD (Pipeline)

É a esteira da fábrica. Pega o código do programador, testa, cria o container e lança no servidor (Deploy) de forma 100% automatizada e segura.
