Inteligência Artificial

Sem pânico e sem magia negra. Aprenda como a IA realmente funciona e como ela atua como um "estagiário superdotado" para impulsionar Produtos, Engenharia e Negócios.

Machine Learning

Em vez de escrevermos as regras (ex: "se for vermelho, é maçã"), nós mostramos 1000 fotos de maçãs para o computador, e ele aprende o padrão sozinho.

Exemplo real: O algoritmo de recomendação do Netflix.

GenAI & LLMs

Inteligências Artificiais treinadas lendo basicamente a internet inteira. Elas não "pensam", elas preveem qual é a palavra mais provável de vir a seguir, como um super corretor ortográfico.

Exemplo real: ChatGPT, Claude, GitHub Copilot.

RAG (Retrieval)

Imagine dar um livro de regras da sua empresa para a IA ler antes dela responder ao usuário. Isso é o RAG: buscar informações na sua base de dados privada para gerar respostas certas sem alucinar.

Exemplo real: Chatbot de Atendimento (Zendesk AI).

IA no dia a dia do Product Manager

A IA não vai roubar seu emprego. Um PM que sabe usar IA vai roubar seu emprego. Veja como aplicar hoje:

  • Discovery Acelerado Use o ChatGPT para analisar a transcrição de 10 entrevistas no Zoom e resumir os principais "Jobs to Be Done" dos usuários.
  • Geração de User Stories Passe os requisitos em texto bruto para o Claude e peça para ele quebrar em User Stories no formato Jira com Critérios de Aceite.
  • Análise de Dados Suba um CSV com o funil de conversão no ChatGPT Data Analyst e peça "Quais as maiores anomalias nesse funil?".
