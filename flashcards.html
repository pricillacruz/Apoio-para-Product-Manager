Conceito Básico

O que é um Product Manager?

Toque para revelar

Resposta

Profissional responsável por definir a visão e estratégia do produto, conectando negócio, tecnologia e usuário para resolver problemas reais.

Conceito Básico

O que é Backlog?

Toque para revelar

Resposta

Lista priorizada de tudo que o time deve construir, investigar ou resolver. É vivo: muda conforme o aprendizado e a estratégia evoluem.

Conceito Básico

O que é uma Sprint?

Toque para revelar

Resposta

Período fixo e curto de trabalho (geralmente 2 semanas) em que o time entrega um incremento de produto testável e potencialmente utilizável.

Conceito Básico

O que é Stakeholder?

Toque para revelar

Resposta

Qualquer pessoa ou grupo com interesse ou que é impactado pelo produto — inclui executivos, clientes, time de engenharia e parceiros.

Conceito Básico

O que é MVP?

Toque para revelar

Resposta

Minimum Viable Product: a versão mais simples do produto que gera aprendizado real com usuários reais, gastando o mínimo de esforço possível.

Conceito Básico

O que é User Story?

Toque para revelar

Resposta

Descrição de funcionalidade do ponto de vista do usuário: "Como [perfil], quero [ação] para que [benefício]." Foco em valor, não em solução técnica.

Conceito Básico

O que é Discovery?

Toque para revelar

Resposta

Fase de investigação contínua para entender problemas reais e validar hipóteses antes de construir. Reduz o risco de criar algo que ninguém precisa.

Conceito Básico

O que é KPI?

Toque para revelar

Resposta

Key Performance Indicator: métrica usada para medir o desempenho em relação a um objetivo estratégico. Ex: taxa de ativação, retenção D7, receita por usuário.

Conceito Básico

O que é Roadmap?

Toque para revelar

Resposta

Planejamento visual e comunicativo da evolução do produto ao longo do tempo. Não é uma lista de tarefas — é a expressão da estratégia para os stakeholders.

Conceito Básico

O que é Feedback Loop?

Toque para revelar

Resposta

Ciclo contínuo de coletar → analisar → agir sobre feedbacks de usuários e dados. Quanto mais curto o loop, mais rápido o aprendizado do time.

Intermediário

O que é o framework RICE?

Toque para revelar

Resposta

Framework de priorização: Reach × Impact × Confidence ÷ Effort. Quanto maior o score, mais prioritário. Elimina o vício de priorizar pelo grito do stakeholder.

Intermediário

O que é North Star Metric?

Toque para revelar

Resposta

A única métrica principal que melhor representa o valor central entregue ao usuário. Alinha o time em torno do que realmente importa no longo prazo.

Intermediário

O que é OKR?

Toque para revelar

Resposta

Objectives and Key Results: framework de metas com objetivo inspirador (qualitativo) e resultados mensuráveis (quantitativos). Conecta estratégia à execução.

Intermediário

O que é Churn?

Toque para revelar

Resposta

Taxa de cancelamento ou abandono do produto por usuários em um período. Alto churn indica que o produto não está entregando valor suficiente para reter.

Intermediário

O que é Feature Flag?

Toque para revelar

Resposta

Mecanismo técnico que permite ligar ou desligar funcionalidades em produção sem novo deploy. Viabiliza rollouts graduais e testes A/B com segurança.

Intermediário

O que é Product-Market Fit?

Toque para revelar

Resposta

Estágio em que o produto resolve tão bem o problema que a demanda cresce organicamente. Usuários recomendam, retornam e ficam frustrados se o produto sumir.

Intermediário

O que é Teste A/B?

Toque para revelar

Resposta

Experimento que compara duas versões de uma funcionalidade expostas a grupos distintos para determinar, com dados, qual performa melhor.

Intermediário

O que é UX Research?

Toque para revelar

Resposta

Conjunto de métodos (entrevistas, testes de usabilidade, mapas de calor) para entender comportamento, motivações e dores dos usuários com evidências.

Intermediário

O que é GTM (Go To Market)?

Toque para revelar

Resposta

Estratégia de lançamento de produto ou feature: comunicação, treinamento de suporte, rollout gradual e adoção pelos usuários. Garante que a entrega seja usada.

Intermediário

O que é Cost of Delay?

Toque para revelar

Resposta

Custo ou perda financeira/estratégica gerada pelo atraso no lançamento de uma iniciativa. Ajuda a justificar prioridades além do esforço técnico.

Avançado

Qual a diferença entre Output e Outcome?

Toque para revelar

Resposta

Output = entrega (feature criada). Outcome = resultado de negócio gerado. PMs de alto nível gerenciam outcomes, não apenas outputs.

Avançado

O que é Continuous Discovery?

Toque para revelar

Resposta

Prática de realizar pesquisa com usuários de forma contínua e sistemática durante toda a execução — não apenas em fases isoladas antes do roadmap.

Avançado

O que é Jobs to be Done (JTBD)?

Toque para revelar

Resposta

Framework que analisa qual "tarefa" o usuário "contrata" o produto para fazer em seu contexto real — independente das características do produto.

Avançado

Qual a diferença entre Métricas de Saúde e de Impacto?

Toque para revelar

Resposta

Saúde = o produto funciona? (uptime, latência, bugs). Impacto = o produto gera valor? (retenção, ativação, receita). Ambas são necessárias.

Avançado

O que é o Triângulo de Ferro?

Toque para revelar

Resposta

Restrição clássica: Escopo, Custo e Tempo. Aumentar o escopo exige mais tempo ou dinheiro. O PM gerencia esse trade-off com os stakeholders.

Avançado

O que é Dark Launch?

Toque para revelar

Resposta

Lançar uma feature para usuários reais em produção sem exibi-la na interface. Testa performance e estabilidade com tráfego real antes do rollout visual.

Avançado

O que é o anti-pattern "Feature Factory"?

Toque para revelar

Resposta

Time focado em lançar features sem medir impacto ou validar resultados. Muita entrega, pouco aprendizado. O product sense fica atrofiado.

Avançado

O que é "Liderança por Contexto"?

Toque para revelar

Resposta

Compartilhar o contexto estratégico (problema, dados, objetivos) para que o time tome decisões autônomas e alinhadas — sem controlar cada tarefa.

Avançado

O que é "Hipótese como Fato"?

Toque para revelar

Resposta

Anti-pattern de tratar suposições não validadas como verdades, pulando o discovery. Leva a construir soluções para problemas que não existem.

Avançado

O que é o Paradoxo da Inovação em escala?

Toque para revelar

Resposta

Quanto mais um produto gera receita e escala, mais difícil é justificar apostas de inovação disruptiva — pois o risco de perturbar o negócio atual aumenta.
