A Experiência

User Experience

O produto pode ter o código mais limpo e a infraestrutura mais robusta. Mas se for confuso para o usuário, ele desinstala em 5 segundos.

Não é "fazer tela bonita"

A maior confusão do mercado: achar que UX e UI são a mesma coisa.

UX (Experiência)

É a ciência de entender o comportamento humano. Onde o usuário clica? Por que ele desiste da compra? O botão faz sentido estar ali?

  • Pesquisas e Entrevistas
  • Arquitetura de Informação
  • Wireframes (Rascunhos)

UI (Interface)

É a estética visual. As cores corretas, o tamanho da fonte, a sombra no botão e o espaçamento para deixar tudo harmônico.

  • Design Systems
  • Cores e Tipografia
  • Protótipos de Alta Fidelidade
Analogia da Casa: UX é a planta baixa da casa (decidir que o banheiro deve ficar perto do quarto e não na cozinha). UI é a pintura, os móveis bonitos e a decoração final.

Como UX atua na Equipe?

Com Produto (PM)

O PM diz "Temos um problema de abandono de carrinho". O UX conduz entrevistas com clientes para entender o porquê.

UX / Product Designer

Mapeia a jornada do usuário e desenha um fluxo simplificado no Figma. Testa com 5 clientes reais antes de pedir para construir.

Com Engenharia

Passa as telas prontas via Hand-off (Figma). Discute com os devs se aquela animação mirabolante é viável de programar a tempo.
